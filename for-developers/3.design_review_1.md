## レビュー
### 1.[MUST] 全体の画面エリア配置
- 外部リンクエリアがない(要件漏れ)
- 画面領域の分割が機能しておらず、「保存」やフィルタがどこに効くのかわかりにくい
- サマリが一番下にあって機能していない(一番目立つ位置、少なくとも見える位置に置きたい)
- 改行ルールが均一でない箇所があり、画面比次第でレイアウトが崩壊する
- [x] カードかel-containerといった領域で「通知」「タスク」「サマリ」「外部リンク」区分を分ける
- [x] サマリはヘッダ真下にstickyかfixedで固定する
- [x] 通知はサマリ直下に配置する
- [x] 外部リンクは重要度が最も低いので一番下に配置する
- [x] 保存ボタンをタスク一覧領域に移動する(タスク追加の右隣)
- [x] 任意入力が入る箇所は必ず改行させないようにする(...を置く)

### 2.[MUST] 通知エリアの縦幅と情報密度の改善
- 通知エリアが縦幅を取りすぎていて情報密度も少なすぎる
- [x] カード形式はなくリスト形式で画面固定せず重要度の高い数件をデフォルト表示し、それ以外はアコーディオンで開閉可能にする
- [x] (改修時のデグレ対応)既読の付け方が分かりにくかった問題を修正: 「未読」タグと「既読にする」ボタンを明示表示し、行クリック(既読化+該当タスクへジャンプ)とボタンクリック(既読化のみ)を区別

### 3.[MUST] タスクのフィルタのデザイン構成
- プレイスホルダーだけのラベルはNG
- 改行がレスポンシブ対応としては不十分
- 日付範囲選択が長すぎて、タスク名が短すぎる
- フィルタのクリア設定が機能していない
- １人ずつしかタスクを絞り込めない
- [x] ラベル幅は入力値から想定される幅に最大値、最小値を固定する(タスク名は20字想定)
- [x] ラベルは全体タイトルが「(フィルタアイコン)絞り込む」で「メンバー」「期限」「ラベル」「タスク名」「ソート」にする
- [x] 改行有無はCSSで制御し、改行されるのであれば縦一列表示(項目ラベルはtop)に変更
- [x] クリアボタンを追加する
- [x] 表示メンバーは複数選択プルダウンにする

### 4.[MUST] ボタンデザイン
- ボタンがプレーンテキストと同化していて、押せるかどうかが不明瞭
- ホバーすると反応するが、それだけでは不十分
- [x] ボタンとしてわかる見た目(primaryボタン)にする
- [x] 多くのボタンがprimaryになるので保存はsuccessボタンにする

### 5.[MUST] 変更有無の確認要素
- どのタイミングでタスクの変更が確定するか画面からでは判断できない
- 変更確定のタイミングにおける確認も不十分
- [x] 何らかの変化がある場合はトーストで「N件のタスクを編集中です。<wbr>変更内容を確定させる場合は<wbr>「保存」ボタンを押下してください。」と常時表示させる。
- [x] 保存ボタンの文言を「変更したタスクを保存」に変更し、変更時のみ活性状態にする。
- [x] 保存ボタン押下時に、変更内容を示したel-dialogを表示させて、確定確認をさせる

### 6.[MUST] カンパン説明のツールチップ
- 文量が多いのでツールチップには向かない
- [x] 改行で漏れているところはアコーディオンにする(youtubeコメントの詳細と同じUI)

### 7.[SHOULD] カンパンの縦幅
- 横幅はそろっているが縦幅がバラバラ
- 全角20文字分はタイトルのスペースが欲しい(改行される場合は...)
- どうせラベルや説明の改行数が固定されているなら高さも固定できるはず
- [x] カンパンカードの高さを固定する
- [x] タイトルの改行を制限する

### 8. [SHOULD] モバイルのカンパンデザイン
- スクロールが必要になる時点でモバイル式のカンパンデザインにしたい
- [x] 未着手等をアコーディオンにして、縦に配置する
- [x] 「レーン」ラベルは左に配置する
- [x] モバイルのときは説明は一行のみ表示でアコーディオンにする

### 9. [SHOULD] タスクを追加の導線
- カンパンの一番下に＋アイコンでタスク追加に行ける導線が欲しい
- [x] + アイコンでタスク追加ダイアログを開けるようにする
- [x] ダイアログではレーンを初期表示できるようにする
